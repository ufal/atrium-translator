# The command line

For users who need the exact meaning and default of a flag, or an exit code. It lists every flag of `main.py`, the
batch entry point, its exit codes, and the repository's other scripts; run them from the repository root. Examples
are in [the usage guide](../usage.md); where each setting can also come from, in
[configuration.md](../configuration.md).

## `main.py`

```bash
python main.py [input_path] [flags]
```

| Flag                    | Default                                                                                                                      | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|-------------------------|------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `input_path`            | `input_path` in config.txt                                                                                                   | A single source file, a directory of XML files, or a `.txt` file listing URLs (each downloaded to `--download-dir`). A `.txt` inside a directory is read as a URL list too (since v1.6.0-beta).                                                                                                                                                                                                                                                                                                                       |
| `--output`, `-o`        | `output` in config.txt, else `./translated_<target_lang>`                                                                    | With one input file, a name ending in `.xml` is the translated file itself (since v1.6.0-beta; it used to become a directory); otherwise the output directory.                                                                                                                                                                                                                                                                                                                                                        |
| `--source_lang`, `-src` | `source_lang` in config.txt (the shipped file says `auto`), else `cs`                                                        | The source language (`cs`, `fr`, …), or `auto` to detect it ([the rules](../how-it-works.md#source-language-identification)). Codes such as `CS`, `cs-CZ` or `ces` are read as `cs`.                                                                                                                                                                                                                                                                                                                                  |
| `--default-source-lang` | `default_source_lang` in config.txt → `DEFAULT_SOURCE_LANG` → `cs`                                                           | With `auto`, the language used when detection cannot be trusted and neither the element's label nor the document's language settles it.                                                                                                                                                                                                                                                                                                                                                                               |
| `--target_lang`, `-tgt` | `target_lang` in config.txt, else `en`                                                                                       | The target language. A pair the backend cannot translate is **refused before any file is touched** (exit 1), with the pairs the backend offers: LINDAT has, for instance, no `cs-it` or `hu-en` model. With `auto`, the default source language is checked the same way. (Before 2026-10-18 LINDAT translated such a run from Czech into English without a word.)                                                                                                                                                     |
| `--formats`             | `formats` in config.txt (the shipped file says `alto.xml`); with `--xpaths`, `xml,txt` instead of it; else `xml`             | Comma-separated extensions to process, e.g. `alto.xml,txt` or `xml,txt`. `txt` reads a file of URLs. Given on the command line, it also names the mode: a list with `alto.xml` is ALTO, any other metadata. From config.txt it only picks the files a folder scan takes.                                                                                                                                                                                                                                              |
| `--config`, `-c`        | `config.txt`                                                                                                                 | The configuration file.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `--alto`                | off                                                                                                                          | ALTO in-place translation mode for the whole run, as `--formats` with `alto.xml` is. Without `--alto`, `--xpaths` and `--formats` on the command line, each file's root element decides (since v1.6.0-beta): `<alto>` is ALTO, any other root a metadata record. A named mode wins, with a warning when a file's root disagrees.                                                                                                                                                                                      |
| `--xpaths`              | `fields` in config.txt (`amcr-fields.txt`)                                                                                   | A `.txt` file of XPaths, one per line (`#` comments allowed), for metadata mode. Works with any XML schema.                                                                                                                                                                                                                                                                                                                                                                                                           |
| `--xsd`                 | —                                                                                                                            | A URL or local path of an XSD to validate the output against (metadata mode). A record inside an OAI-PMH envelope is validated, not the envelope. Each record's verdict is logged, the run ends with one `XSD: N/M record(s) valid` line, and the paradata records `xsd_validation` (`valid`, `invalid` doc ids, `strict`). An XSD that cannot be loaded stops the run (exit 1). AMČR 2.2 accepts `replace` output and rejects `append` output ([output mode](../usage.md#choose-the-output-mode-replace-or-append)). |
| `--xsd-strict`          | `XSD_STRICT`, else off                                                                                                       | With `--xsd`, a record that fails validation counts as a failed document: exit 3, the XML is still written. Off, a warning only.                                                                                                                                                                                                                                                                                                                                                                                      |
| `--vocabulary`          | `vocabulary` in config.txt (`data_samples/vocabulary.csv`), if that file exists                                              | A vocabulary CSV (`source_lemma,target_translation`, [the format](vocabulary.md)): Tag-and-Protect with `lindat`, the prompt glossary with `openai_compatible` and `ct2`. A path that does not exist stops the run (exit 1); clear `vocabulary =` in config.txt to translate without one.                                                                                                                                                                                                                             |
| `--backend`             | `translation_backend` in config.txt → `TRANSLATION_BACKEND` → `lindat`                                                       | `lindat` (LINDAT CUBBITT), `openai_compatible` (an OpenAI-compatible language-model API, set by the `LLM_*` variables) or `ct2` (a self-hosted CTranslate2 model; install `requirements-ct2.txt` and set the `CT2_*` variables). [The three backends](../how-it-works.md#the-three-backends).                                                                                                                                                                                                                         |
| `--fast-align`          | off                                                                                                                          | ALTO only. Distribute a block's tokens by source word count instead of translating each line as an anchor: far fewer requests, slightly coarser line splits.                                                                                                                                                                                                                                                                                                                                                          |
| `--output-mode`         | `output_mode` in config.txt → `OUTPUT_MODE` → `replace`                                                                      | `replace` or `append`: how the translation is written into the document ([output mode](../usage.md#choose-the-output-mode-replace-or-append)).                                                                                                                                                                                                                                                                                                                                                                        |
| `--document-json`       | —                                                                                                                            | A baseline ATRIUM document record to add to (the cross-tool record passed along the pipeline). Its `doc_id` is kept. In a batch, a directory: each document's baseline is `<dir>/<doc_id>.document.json` when it exists; one file for a batch is refused (exit 1).                                                                                                                                                                                                                                                    |
| `--document-json-out`   | `<doc_id>.document.json` beside the output                                                                                   | Where to write the updated record. In a batch, a directory: each record is `<dir>/<doc_id>.document.json`; a `.json` file for a batch is refused (exit 1), since each record overwrote the last.                                                                                                                                                                                                                                                                                                                      |
| `--download-dir`        | `<output>/downloaded_inputs`                                                                                                 | Where URL inputs are downloaded.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

A run named metadata (`--formats xml`) without XPaths (from `--xpaths` or `fields`) stops with exit 1. Without a
mode flag, a record with no XPath targets fails on its own (exit 3) and the ALTO pages are still translated. A
command line with `--xpaths` and no `--formats` is a metadata run with `xml,txt`, whatever config.txt says. A
directory scan in a named metadata mode leaves `*.alto.xml` files out; a file named on the command line is
processed.

## Exit codes

| Code | Meaning                                                                                                                                                                                                              |
|------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `0`  | Success.                                                                                                                                                                                                             |
| `1`  | Usage or configuration: a missing input path, a named metadata mode without XPaths, a missing vocabulary, a backend that cannot start, a refused language pair, an XSD that cannot be loaded. Nothing is translated. |
| `2`  | No input matched the allowed formats.                                                                                                                                                                                |
| `3`  | One or more documents failed, or, with `--xsd-strict`, a record is invalid.                                                                                                                                          |

A document that fails is logged and the batch goes on, but the process still exits 3, so a Kubernetes `Job` or a
cron wrapper sees it. A transport failure (LINDAT unreachable after `LINDAT_MAX_RETRIES`) fails the document; a
degenerate reply does not: it costs one segment, kept in its source language and logged `untranslated`.

## Other entry points

| Script                   | Purpose                                                                                         | Key flags                                                                                                                                                                                                                                                                                                          |
|--------------------------|-------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `load_vocab.py`          | Build the vocabulary CSV from atrium-keyword-extract's release, or harvest AMČR and TEATER      | `--from-release`, `--asset`, `--sha256`, `--description-chars`, `--out`, `--delay`, `--skip-amcr`, `--skip-teater` ([usage](../usage.md#build-the-vocabulary))                                                                                                                                                     |
| `eval/bakeoff.py`        | Compare backends: reference-less checks, and chrF, BLEU and COMET when references are given     | `--samples`, `--xpaths`, `--backends`, `--label`, `--kinds`, `--vocabulary`, `--refs`, `--source_lang`, `--limit`, `--combine`, `--out`, `--summary-out`, `--comet-model`, `--comet-qe-model`, `--comet-gpus`, `--max-consecutive-failures` ([the bake-off](../evaluation/backends.md#the-bake-off-evalbakeoffpy)) |
| `eval/langid_report.py`  | Per block, FastText's top guesses beside the resolved language and its basis                    | `path`, `--xpaths`, `--languages`                                                                                                                                                                                                                                                                                  |
| `eval/lindat_probe.py`   | Send one text N times to the live LINDAT endpoint and print the pattern of good and bad replies | `--n`, `--text` (`daily` for the daily check's sentence), `--model`, `--pause`, `--max-bad` ([LINDAT's replies](../evaluation/lindat-replies.md))                                                                                                                                                                  |
| `check_version.py`       | Release gate: the tag equals `CITATION.cff` and `para_config.txt`                               |                                                                                                                                                                                                                                                                                                                    |
| `atrium_rocrate.py`      | RO-Crate 1.2 export of finished records, and the service's `CreateAction`; its own CLI          | `--out-dir`                                                                                                                                                                                                                                                                                                        |
| `atrium_openapi.py`      | Export and compare the service's OpenAPI document                                               | `export --app service.api:app --out service/openapi.json`, `compare`                                                                                                                                                                                                                                               |
| `service/healthcheck.py` | The Docker health check; standard library only, always probes loopback                          |                                                                                                                                                                                                                                                                                                                    |

The `eval/` scripts call real backends over the network and are run by hand, not in CI; `eval/` is not in the images.
