## 🎯 Goal
Pick the translation base model with evidence, keep the backends swappable, and give a permissive self-hosted recipe. CUBBITT (LINDAT) stays the default unless an alternative wins on fidelity and keeps the XML/ALTO structure.

## 🧩 What exists (`v1.4.0-beta`, plus the 10-18 round above)
- **One seam.** `TranslationBackend` Protocol + `get_backend()` (`processors/backend.py:93`). It is called from `main.py:732` and `service/api.py:317`. Resolution order: `--backend` → `config.txt` → `TRANSLATION_BACKEND` → `lindat`.
- **Backends:**
  - **`lindat`:** CUBBITT; Tag-and-Protect with UDPipe for terms; CC BY-NC-SA 4.0.
  - **`openai_compatible`:** any OpenAI-compatible endpoint (`LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`); prompt glossary; temperature 0; length-ratio guard; licence = provider terms.
  - **`ct2`:** CTranslate2 with EuroLLM (1.7B/9B) or MADLAD-400 (Apache-2.0), NLLB-200 (CC BY-NC) or OPUS-MT (CC BY). Loaded at service start (`warm()`).
- **Every reply is checked** (`processors/quality.py`): empty, runaway, truncated, looping or mixed-script output is re-requested, re-run at the end of the document, or kept as source.
- **Permissive recipe:** `--backend ct2` with an Apache-2.0 model, an explicit `--source_lang`, and the CC0 vocabulary. A EuroLLM run with the glossary resolves to MIT.
- **The harness:** `eval/bakeoff.py` measures per-segment similarity, terminology hit rate, and optionally chrF/BLEU/COMET (`--refs`) and COMET-QE. It has never run.
