## ✅ What is shipped (`v1.4.0-beta`)
- **Metadata mode:** XPath fields (`amcr-fields.txt`); `replace` or `append`; `--xsd` validates the record inside its OAI-PMH envelope; `--xsd-strict`.
- **ALTO mode:** `append` keeps every `CONTENT` and adds `<ALTERNATIVE PURPOSE="translation:en">`; `replace` relabels `LANG`. ALTO is not in the pilot.
- **The reply guard:**
  - every segment is checked (empty, runaway, truncated, looping, mixed-script);
  - LINDAT re-requests a degenerate reply;
  - failed segments are re-run at the end of the document, or kept as source, never blanked;
  - the `_log.csv` `status` column records the outcome: `ok`, `rerun`, `approx_alignment`, `untranslated` or `unsupported_lang`.
- **Language:** a FastText guess counts only if long, confident and translatable. Otherwise the fallback order is element → document → default (`cs`). `translations.detected_source_lang` and `unsupported_source_langs` are recorded.
- **Licence per run:** a LINDAT run is CC BY-NC-SA 4.0 (CUBBITT, UDPipe models). The vocabularies are CC0.
