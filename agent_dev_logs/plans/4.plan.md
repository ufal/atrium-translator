## Execution plan

### A — housekeeping (before C)
1. **Milestone.** Set the due date to the end of October. Correct the checklist (`ct2` is registered, and the §5/§6 references are fixed).
2. **`data_samples/`.** Either restore the LINDAT replace folder of `v1.2.2-beta` (run `260928-110452`) and keep the `ct2` run in a folder of its own, or say in `data_samples/README.md` that the folder is the `ct2` run `260928-113756`. #46's production shape is the LINDAT one.

### B — the LLM translation arm (AMČR, #72, 10-13)
3. **Glossary with descriptions.** `processors/llm_translator.py`: each matched term gets its description (`note_en`, falling back to `note_cs`), read from the vocabulary asset's flat JSON, and capped like the pairs. Test: a matched term with a note appears in the prompt with it; one without a note, without it.
4. **A vocabulary for `/translate`.** `service/api.py:317` passes `vocab_path=None`. Add `VOCABULARY_PATH` (`.env.example`, `/info`, the spec's settings): unset means no vocabulary, as now. Test: with the variable set, the LLM backend's prompt carries the glossary.
5. **The model.** Qwen 3.8 (K4TEL, 09-30) or another capable open model, served OpenAI-compatibly (vLLM on the cluster, where keyword-extract#2 already runs Qwen 3.8). Record its licence in `para_config.txt` as a model-specific row, never a generic "LLM" row (hub #6).
6. **Live smoke** of the CLI and `/translate` with that backend on the AMČR sample.

### C — the bake-off
7. Run, on the cluster:

   ```bash
   python -m eval.bakeoff --backends lindat,openai_compatible,ct2 \
     --samples data_samples/my_documents --xpaths amcr-fields.txt \
     --vocabulary <keyword-extract's curated list, #72 B.2> --source_lang cs \
     --out bakeoff.csv
   ```

   - Two arms for `openai_compatible`: with and without descriptions.
   - `ct2` with EuroLLM-1.7B (and 9B if the node allows), measuring the widening re-run.
   - Weight the AMČR `metadata-en` free-text fields. ALTO is a secondary slice, reported apart.
   - With references (`--refs`) where Dana or David can supply them for a subset; otherwise COMET-QE and a manual review of terminology.
8. Commit `bakeoff.csv` and its summary, and post the table on #4.

### D — the decision
9. Choose the default:
   - keep `lindat` unless an alternative wins on fidelity, with no XML/ALTO damage;
   - name the permissive self-hosted choice;
   - name the LLM alternative AMČR asked for.
10. Rewrite `docs/translation-backends.md` §"Recommendation" and §"Suggested next steps" from the results. Update `config.txt` only if the default changes.
11. Release, then close #4 with the table and the decision.
