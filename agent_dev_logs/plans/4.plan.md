## Execution plan

### C — the bake-off (job T1)
1. **Push** the 10-18 files to `test`. On the cluster, in `/lnet/work/projects/atrium/GITHUB/atrium-translator`: `git fetch --force origin test && git merge -X theirs --no-edit origin/test`.
2. **Prep** on a networked node (`issue4_bakeoff_prep.sh`):
   - `venv-bakeoff`;
   - EuroLLM-1.7B/9B into `cache/translator_models/hf`;
   - Qwen3.8-27B and -FP8 into `HF_HOME`;
   - prints Qwen's licence;
   - checks keyword-extract's `venv-kw` for vLLM.
3. **Job** (`issue4_bakeoff_job.sh`): `sbatch -w dll-4gpu1 …` (bf16) or `sbatch -p gpu-troja --gres=gpu:2 …` (FP8, TP=2). Stages:
   - 00: tests;
   - 05: CT2 conversion;
   - 10: lindat;
   - 20/21: ct2;
   - 30: the LLM arms;
   - 40: combine;
   - 50: samples;
   - 60: live lane;
   - 90: report.

   A stage that cannot run (no LINDAT from the node) says so and prints the command for a networked node.
4. **Archive** back: `report`, `runs`, `logs`, `code_state`. The samples go into the repository (`data_samples/ct2_translated_files/xml`, LINDAT's `in-place_translated_files/xml`) and the combined CSVs into `eval/results/issue4_bakeoff_2610/`.

### D — the decision
5. From the matrix:
   - keep `lindat` unless an alternative wins on fidelity with no XML damage;
   - name the self-hosted fallback (EuroLLM 1.7B or 9B);
   - name the LLM alternative and whether descriptions help;
   - decide whether the image sets `VOCABULARY_PATH`.
6. Add Qwen3.8's licence row to `para_config.txt`, with the licence read in the prep log. Write the docs' final Recommendation.
7. #4 comment with the table; v1.5.0-beta (row, notes) once immutable releases are on; close #4.
